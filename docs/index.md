# 开源组件治理文档

一个面向工程团队的开源组件治理资料站，聚焦开源组件使用规范、License 理解和合规落地实践。

## 内容方向

- 开源组件引入与使用规范
- 常见 License 类型与差异
- 商用、修改、分发、闭源边界判断
- 合规流程、检查清单与模板
- 典型场景案例与发布声明参考

## 说明

本项目提供工程治理层面的通用指导，不替代正式法律意见。

对外商业分发、强 Copyleft License 使用、第三方源码修改再分发、闭源产品嵌入和专利相关场景，仍应结合正式法务或合规流程单独评估。
